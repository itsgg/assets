# assets

Public distribution repository for releases, media, audiobooks, and binary artifacts associated with [itsgg.com](https://itsgg.com).

## Purpose

This repository hosts public releases and downloadable media artifacts to:
- Provide fast, unauthenticated, and reliable public downloads.
- Keep source code repositories lightweight and free of large binaries.
- Ensure immutable versioning for published works and distributions.

## Releases

Release assets are published on the [Releases page](https://github.com/itsgg/assets/releases).

- **Audiobooks (`books-v1`):** Complete M4B audiobook editions of published books:
  - *The Long Argument* (A concise map of Hindu philosophy)
  - *The One Who Notices* (A practical path through the restless mind)
  - *The One Who Acts* (A life manual from the Bhagavad Gita and the Yoga Sutras)
  - *The Practical Yoga Sutras* (A manual for a steady mind and a well-lived life)

## Fonts

The web fonts itsgg.com uses live in [`fonts/`](fonts/), served by jsDelivr from the full commit hash of the `fonts-v1` tag. See [fonts/README.md](fonts/README.md).
