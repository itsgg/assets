# Softnote previews

Preview clips for the post [A keyboard sound that says less](https://itsgg.com/blog/2026/10/24/a-keyboard-sound-that-says-less/), built from the takes of the Softnote soundpack ([itsgg/omathock](https://github.com/itsgg/omathock/tree/feat/softnote-soundpack/soundpacks/softnote), MIT) at the pack's full level.

- `softnote-keys.wav`: a letter before each of Space, Enter and Backspace, 600 ms apart.
- `softnote-takes.wav`: the eight letter takes, softest to hardest, 450 ms apart.
- `softnote-typing.wav`: a line typed at a simulated pace, with one typo fixed.

itsgg.com loads them through jsDelivr from the full commit hash of the `audio-v1` tag.
